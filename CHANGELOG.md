# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии: [Semantic Versioning](https://semver.org/lang/ru/) (`0.x` — пререлиз / ранний продукт).

Сборки **не хранятся в git**. Готовые бинарники — в CI Artifacts / Releases.

## [0.2.0] — 2026-10-21

### Добавлено

- Раздел «Обзор»: чужой worklog (только просмотр) и пресеты «Мои задачи»
- Навигация HomeShell (Неделя / Обзор / Настройки)
- Тема оформления: system / light / dark
- Календарь переносов: `calendar/holiday_transfers.json` + opt-in URL и кэш в настройках
- Linux: «Добавить в меню приложений» (AppImage / desktop)
- Настройка «Неделя начинается с» (Пн / Вс)
- Отчёт о сбое: Settings → скопировать (без секретов); скрипт `tool/collect_support_report.sh` только в репо

### Исправлено

- macOS: Keychain `-34018` (legacy Keychain для unsigned-сборок) и `network.client` в entitlements
- Календарь выбора дат: неделя с понедельника (`flutter_localizations`, ru)
- Zone mismatch при старте (убран `runZonedGuarded` после `ensureInitialized`)

### Изменено

- Обзор «По пользователю»: дни с цветной шапкой и полной датой
- Экран дня: списания сгруппированы по задаче в карточках

### Известные ограничения

- Запись в чужой worklog (админ-токены) — не в этом релизе
- Win/macOS: unsigned builds; первый запуск через Gatekeeper (right-click → Open)

## [0.1.0] — 2026-09-14

Первый публикуемый срез desktop-клиента worklog для Yandex Tracker.

### Добавлено

- First-run setup: OAuth-токен, ID организации, проверка `/myself`, подстановка логина
- Неделя: суммы по дням (`start`), навигация по неделям, норма часов, выходные и праздники РФ
- День: список списаний, создание / изменение / удаление
- Поиск задач (autocomplete) с пагинацией «Показать ещё»
- Настройки подключения и календарь (выходные / праздники)
- Понятные ошибки сети и API; при 401/403/404 — переход в настройки
- Material 3 тема, иконка приложения (Linux / Windows / macOS)
- Экран «Что нового» в настройках
- CI: analyze + test; desktop-сборки по SemVer-tag (`0.1.0`, `0.1.0-rc.1`, …)

### Известные ограничения

- Пагинация worklog `_search` пока одна страница ответа
- Календарь переносов праздников зашит на ближайшие годы (обновление без релиза — в бэклоге)
